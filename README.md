- Coach interface with multiple implementations

## 🚀 Getting Started

**Prerequisites:** Java 17+ (the Maven wrapper is included)

**Run the API**

```bash
git clone https://github.com/miladmo68/spring-boot-spring-core.git
cd spring-boot-spring-core
./mvnw spring-boot:run
```
